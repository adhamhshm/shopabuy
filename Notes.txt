- Section 2 - API basics
- get .net info > dotnet --info
- get .net template list 
    > dotnet new list
- create a main/root folder for the application
- create a new solution file for .net in the main folder 
    > dotnet new sln
- see .sln file will be created
- see list of settings for web api template 
    > dotnet new webapi -h
- create an API/ folder in main/root folder with controller template 
    > dotnet new webapi -n API -controllers
- add the project to the solution file 
    > dotnet sln add API/
- run API project > dotnet run
- try open the API localhost url, you see nothing, but in API/ folder, we have Controllers/WeatherForecastController.cs
- go to [localhost-url]/WeatherForecast, should see something related to the code in the WeatherForecastController.cs file
- done with this demo part
- install dependency/extensions in vs code
    > C# Dev Kit, SQLite, SQLite Viewer, NuGet Gallery
- use "solution explorer" in the explorer tab/dropdown of the vs code
- use Program.cs as the main file for running .net application
- see appsettings.json and appsettings.Development.json, for development, the later is more significant
- see Properties/launchSettings.json for the app launch configuration, can retain the https
- remove connection not secure warning, run in API folder
    > dotnet dev-certs https --clean
    > dotnet dev-certs https --trust
- create Entities/ folder
- create Product.cs in the Entities/  folder
- use shortcut type "prop" / "propfull" [ENTER], to create property in a c# file

- Section 2 - using entity framework
- use NUGET, look in the cli terminal, in its tab (NuGet Gallery should be installed)
- search for "microsoft.entityframeworkcore" in NUGET
- select the Microsoft.EntityFrameworkCore.Sqlite, Microsoft.EntityFrameworkCore.Design
- choose the version of .NET you are using, and install to API.csproj
- create Data folder

- use shortcut type "ctor" [ENTER], to create constructor in a c# file
- update Program.cs with DbContext services
- update appsettings.Development.json to include "ConnectionStrings:DefaultConnections"

- Section 2 - creating entity framework migration
- install dotnet-ef in API, find in browser for docs
    > dotnet tool install --global dotnet-ef --version 9.0.4
- check if installed
    > dotnet ef
- create initial migrations
    > dotnet ef migrations add InitialCreate -o Data/Migrations
- update database migrations
    > dotnet ef database update
- see store.db file is created, with SQLite Viewer, to be able to view the file
